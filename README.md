# Geometria Wykreślna – interaktywna platforma

Nauka do kolokwium z Grafiki Inżynierskiej / Geometrii Wykreślnej (1. semestr):
6 modułów (Monge, wielościany, bryły obrotowe, aksonometria, rzut cechowany, perspektywa),
konstrukcje krok po kroku (CO / JAK / DLACZEGO) z powiązanym widokiem 3D i arkuszem 2D.

Vanilla JS + Three.js + SVG, bez budowania – wystarczy otworzyć `index.html`.
Link do konkretnego kroku: `index.html#m1-transformacja/5`.
